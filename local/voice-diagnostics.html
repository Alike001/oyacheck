    Browser playback voices

      Chrome on Linux: no playback voices?

      Chromium's Linux Speech Dispatcher backend requires --enable-speech-dispatcher. Save your browser work and fully quit Chrome normally before relaunching with google-chrome --enable-speech-dispatcher http://127.0.0.1:4190/voice-diagnostics. An already-running Chrome can ignore a new startup flag. Refresh here after voices load. Do not disable the sandbox or install packages blindly. If voices still fail, check Speech Dispatcher connectivity and Ubuntu Sound output.
